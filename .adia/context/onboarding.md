## Architecture in 30 Seconds
Benchrs is a **mobile-first PWA** for amateur football team management. Built with Next.js 16 App Router but used almost entirely as a **client-side SPA**: pages are `"use client"`, data is fetched from Supabase via client SDK in `useEffect`, and there's a custom `useQueryCache` (30s TTL) for deduplication. The dashboard wraps everything in `AuthProvider` → `TeamProvider` which cascade 5+ Supabase queries before any content renders. AI features (training, reports, challenges) call Mistral via API routes. Real-time features (chat, live match) use Supabase Realtime.

## Common Pitfalls
- **RLS recursion**: NEVER sub-query the protected table in its own RLS policy — use SECURITY DEFINER functions
- **Supabase singleton**: `createBrowserClient()` is a singleton — realtime channel names MUST be unique (use `useId()`)
- **setState in useEffect**: React Compiler lint flags `setState` in effect callbacks — use `useCallback` that returns data, then `.then(setX)` in the effect
- **`SUPABASE_SERVICE_ROLE_KEY`**: must be the REAL key on Vercel, not a placeholder — otherwise all API routes return 401
- **Deploy to prod**: never push directly to `production` — validate preview first, then `git push origin main:production`
- **framer-motion**: listed in dependencies but NOT imported — dead dependency
