# Conventions
> Generated by @init_project on 2026-08-18 — Project benchrs
> Last update: 2026-08-18

## Naming
- **Files**: kebab-case for lib files, PascalCase for components
- **Variables/functions**: camelCase
- **Types/Interfaces**: PascalCase, all in `src/types/index.ts`
- **CSS**: Tailwind utility classes, CSS variables for theming (`--color-gold`, `--color-navy`, `--color-royal`)

## Imports
- Path alias `@/*` → `./src/*`
- Supabase client: `createClient()` from `@/lib/supabase/client` (browser, singleton)
- API auth: `authFetch` from `@/lib/api-client` (adds Bearer token)

## Component Patterns
- Pages are `"use client"` with data fetching in `useEffect`
- Dashboard widgets use `useQueryCache` for deduplication
- Coach-gating: `userRole === "coach" || userRole === "owner"` (per-team from `useTeam()`)
- Parent child selection: `useSelectedChild` hook + `ChildSwitcher` component
- Lazy loading: `LazyMount` (IntersectionObserver) + `next/dynamic` on dashboard

## Git
- **Convention**: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `revert:`)
- **Workflow**: feature branches → `main` (preview) → `production` (merge for deploy)
- **Branch**: production = Vercel prod; main = preview/pre-prod
- **Single contributor**: Bondeau Corentin (351 commits)

## Supabase Patterns
- RLS via SECURITY DEFINER functions (never sub-query the protected table in its own policy)
- `@supabase/ssr` v0.12 singleton — channel names MUST include `useId()` suffix
- Realtime: channels for chat, live match, unread badges
- Admin client via `SUPABASE_SERVICE_ROLE_KEY` (server-side only)

## Lint Rules
- ESLint: `eslint-config-next/core-web-vitals` + `typescript`
- React Compiler lint: `react-hooks/set-state-in-effect` — use `useCallback` that returns data, setState in `.then()`
