## Impact Analysis
- **lib-supabase** is THE critical point — 100% of data flows through it
- **lib-auth** impacts every authenticated page (AuthProvider wraps dashboard)
- **lib-team** impacts every dashboard feature (TeamProvider wraps dashboard)
- **useQueryCache** impacts all dashboard widgets (9 components)
- Modifying **lib-auth** or **lib-team** triggers re-render of the ENTIRE dashboard tree
- Modifying **components-ui** affects ALL pages (shadcn primitives are everywhere)
- **recharts** is loaded synchronously in 4 client components (no code-splitting)
