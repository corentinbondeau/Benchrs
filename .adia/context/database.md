## Realtime Tables
- `chat_messages`, `chat_members`, `chat_channels`, `match_events`, `events`, `match_stats`

## Storage Buckets
- `gallery` — photos/videos (scoped to `gallery/<user_id>/`)
- `challenge_media` — challenge submissions
- `physical_docs` — physical prep documents

## RLS Pattern
- SECURITY DEFINER functions (e.g., `is_team_coach`, `is_global_coach`, `user_club_ids`)
- NEVER sub-query the protected table in its own policy
- `user_visible_team_ids()` for cross-team visibility (club members)
