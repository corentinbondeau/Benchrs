## Responsibility
AuthProvider React context — manages user session, profile, sign-out, and refresh.

## Pattern
1. `useEffect` on mount: `supabase.auth.getSession()` → `fetchProfile(userId)` → `setUser`
2. `onAuthStateChange` listener for session changes
3. `refreshUser()` for manual re-fetch
4. `signOut()` → redirect to `/login`

## Performance Issues (CRITICAL)
- **Blocking waterfall**: `getSession()` + `fetchProfile()` are sequential — UI renders nothing until both complete
- `loading` state starts `true` — children don't render until auth resolves
- Every auth state change re-fetches the full profile (`SELECT *`)
- No caching of profile data between navigations
- `fetchProfile` uses `SELECT *` — could select only needed columns
