## Responsibility
TeamProvider React context — manages multi-team support, club memberships, team switching, and team colors.

## Pattern
1. Waits for `authUser` (from AuthProvider)
2. `loadTeams(userId)`:
   - Query `team_members` with join on `teams` + `clubs` (1st query)
   - Query `club_members` (2nd query)
   - Query `clubs` where `created_by = userId` (3rd query, parallel with 2nd)
   - If club memberships: query `teams` by `club_id` (4th query)
   - Merge + deduplicate teams
   - Apply team colors via CSS variables
3. `switchTeam()` reloads all teams

## Performance Issues (CRITICAL)
- **3-4 sequential Supabase queries** before ANY dashboard content renders
- `loadTeams` runs AFTER `AuthProvider` completes — cascading waterfall
- `switchTeam` re-runs `loadTeams` (full reload for a team switch)
- `localStorage.getItem("selectedTeamId")` + `localStorage.setItem` on every load
- Team colors applied via `document.documentElement.style.setProperty` — causes repaint
- Club membership check adds 1-2 extra queries even for non-club users
