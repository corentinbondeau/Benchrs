## Responsibility
All dashboard pages (32 routes). Mobile-first UI for team management: calendar, matches, trainings, stats, chat, roster, settings, physical, challenge, season, gallery, championship, club, etc.

## Key Files
| File | Role |
|------|------|
| layout.tsx | Dashboard shell: AuthProvider → TeamProvider → TeamGuard → Sidebar/TopBar/BottomNav |
| page.tsx | Dashboard home: role-based (Coach/Player/Parent), 7 widgets with independent data fetching |
| calendar/page.tsx | Calendar view (list/week/month), multi-child support for parents |
| matches/[id]/page.tsx | Match detail: attendance, ratings, MVP, report, live tracker, agenda |

## Patterns
- **ALL pages are `"use client"`** (except convocations/page.tsx)
- Data fetched in `useEffect` via `createClient().from(...)` — NO server-side data fetching
- Coach-gating: `userRole === "coach" || userRole === "owner"`
- `force-dynamic` export on layout.tsx prevents static generation

## Performance Issues
- Dashboard home loads 7+ widgets, each with independent Supabase queries (waterfall)
- No prefetching, no streaming, no suspense boundaries
- Largest pages (1200-2000 LOC) bundle all features into one client component — no code-splitting within pages
- Chat page maintains 2 realtime subscriptions permanently

- `e2e/public.spec.ts` — minimal E2E coverage
