## Internal API Routes (50+)
All routes under `src/app/api/` — Next.js Route Handlers, secured via `getAuthUser` + team/role checks.

### Auth
- `POST /api/auth/register` — user registration
- `POST /api/auth/join-team` — join team with invite code
- `POST /api/auth/create-team` — create team + club
- `POST /api/auth/link-child` — parent → child link
- `POST /api/auth/join-club` — join club committee
- `POST /api/auth/forgot-password` — password reset (anti-enumeration)

### AI (Mistral)
- `POST /api/trainings/generate` — generate training session (Mistral)
- `POST /api/trainings/pdf` — render session as PDF
- `POST /api/matches/report` — generate/read match report (AI or manual)
- `POST /api/announcements/generate` — generate coach announcement
- `POST /api/challenges/generate` — generate weekly challenge
- `POST /api/season/report` — generate season report (AI)
- `POST /api/season/plan` — generate season plan (AI)
- `POST /api/reports/quarterly` — quarterly report (AI)

### Notifications
- `POST /api/notifications/send` — send push + in-app notifications
- `GET /api/notifications/cron` — Vercel cron for scheduled notifications + eve reminders
- `POST /api/notifications/subscribe` — push subscription registration
