# Guide d'utilisation - Import automatique DOFA

## Comment utiliser l'import FFF DOFA?

L'import automatique FFF DOFA vous permet de créer un championnat en quelques clics en récupérant automatiquement:
- ✓ Liste des équipes du club
- ✓ Calendrier des matchs
- ✓ Résultats des matchs
- ✓ Classement en temps réel

## Étape 1: Ouvrir le dialog d'import

1. Allez à l'onglet **"Championnat"**
2. Cliquez sur le bouton **"Import auto FFF"** (icône ⚡)

## Étape 2: Rechercher votre club

Vous avez 2 options:

### Option A: Recherche par nom (recommandé)
1. Tapez le **nom de votre club** dans le champ "Rechercher le club par nom"
   - Exemple: "AS Monaco", "PSG", "OM", etc.
2. Attendez que des **suggestions apparaissent**
3. **Cliquez** sur votre club dans la liste
4. Un message vert confirme: "Club sélectionné: AS Monaco"

### Option B: Recherche par numéro FFF
1. Descendez jusqu'à "Rechercher par numéro FFF"
2. Entrez le **numéro FFF de votre club** (6 chiffres)
   - Exemple: "525816" (AS Monaco)
   - 📌 Trouver le numéro FFF: https://www.fff.fr/
3. Cliquez sur **"Chercher"**

## Étape 3: Sélectionner une équipe

Après la recherche:
1. Une liste d'**équipes** du club apparaît
   - Exemple: "AS Monaco (Ligue 1)", "AS Monaco B (Ligue 2)"
2. **Sélectionnez** l'équipe que vous entraînez en cliquant dessus
3. Un **✓** apparaît à côté de l'équipe sélectionnée

## Étape 4: Importer

1. Cliquez sur le bouton **"Importer"** (bouton doré)
2. Le système va récupérer:
   - 📅 Tous les matchs de la saison
   - 🏆 Le classement en temps réel
   - 📊 Les résultats des matchs
3. Vous serez redirigé vers la page du championnat

## Messages d'erreur - Comment les résoudre?

### ⚠️ "Entrez un numéro FFF valide (6 chiffres)"
- **Problème**: Vous n'avez rien entré
- **Solution**: Tapez le numéro FFF de votre club

### ⚠️ "Numéro FFF invalide. Entrez 1 à 6 chiffres"
- **Problème**: Le numéro contient des lettres ou plus de 6 chiffres
- **Solution**: Entrez uniquement des chiffres (1-6 maximum)

### ⚠️ "Club non trouvé avec ce numéro FFF"
- **Problème**: Le numéro FFF n'existe pas
- **Solution**: 
  - Vérifiez le numéro sur https://www.fff.fr/
  - Essayez la recherche par nom à la place

### ⚠️ "Service FFF indisponible. Réessayez plus tard"
- **Problème**: Les serveurs FFF sont temporairement indisponibles
- **Solution**: Attendez quelques minutes et réessayez

### ⚠️ "Aucune équipe trouvée"
- **Problème**: Votre club n'a pas d'équipes enregistrées
- **Solution**: Vérifiez le numéro FFF ou le nom du club

## Conseils et astuces

### 💡 Recherche par nom
- Tapez au moins **2 caractères**
- Pas besoin de taper le nom complet ("Mon" pour "Monaco")
- La recherche est automatique (pas besoin de cliquer)

### 💡 Trouver le numéro FFF
1. Allez sur https://www.fff.fr/
2. Recherchez votre club
3. Copiez le numéro dans l'URL ou le profil du club

### 💡 Plusieurs équipes
Si votre club a plusieurs équipes (U18, U15, etc.):
- Sélectionnez l'équipe que vous entraînez
- Vous pourrez créer d'autres championnat pour les autres équipes

### 💡 Mise à jour du classement
- Les données importées reflètent l'état actuel du championnat
- Les classements et résultats se mettent à jour après chaque journée

## FAQ

**Q: Comment mettre à jour les données après un match?**
A: Les données se synchronisent automatiquement. Créez un nouveau championnat avec le même code FFF pour les données les plus récentes.

**Q: Peut-on importer plusieurs équipes du même club?**
A: Oui! Créez plusieurs championnat en répétant le processus pour chaque équipe.

**Q: Le numéro FFF ne fonctionne pas?**
A: Essayez la recherche par nom. Si ça ne marche pas, l'API FFF peut être indisponible. Réessayez plus tard.

**Q: Est-ce qu'on peut importer les données après la saison?**
A: Oui! Les données historiques sont disponibles si le club/équipe a participé au championnat.
